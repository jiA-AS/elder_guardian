## 二、ESP-SensairShuttle 主板引脚分配

### 2.1 外置引脚接口（External Pin Interface）

4-pin 接口，自上而下：

| 引脚 | 功能 | 方向 | 备注 |
|------|------|------|------|
| 1 (上) | GPIO5 | 双向 | **默认不可用**，需上件 R14 电阻后方可使用 |
| 2 | GPIO4 | 双向 | |
| 3 | VDD | 电源 | 3.3V 输出 |
| 4 (下) | GND | 电源 | 地 |

> **注意**：GPIO5 默认未引出，若需使用 GPIO5，需在 PCB 上焊接 R14 电阻（0Ω）。

### 2.2 外置 I2C 接口

| 信号 | 说明 |
|------|------|
| **I2C_SDA** | I2C 数据线 |
| **I2C_SCL** | I2C 时钟线 |
| **VDD** | 3.3V 电源 |
| **GND** | 地 |

> **注意**：I2C 接口的具体 GPIO 编号需查阅原理图确认。

### 2.3 外置 RGB 灯带接口

| 引脚 | 功能 | 备注 |
|------|------|------|
| 1 | 信号线 | 连接 WS2812 等 RGB 灯带数据线 |
| 2 | VDD | 5V 电源 |
| 3 | GND | 地 |

> **注意**：RGB 接口的具体 GPIO 编号需查阅原理图确认。

### 2.4 LCD 接口

| 参数 | 值 |
|------|-----|
| **屏幕尺寸** | 1.83 英寸 |
| **分辨率** | 240(H) x 284(V) |
| **驱动芯片** | ST7789P3 |
| **通信接口** | 4-line SPI |
| **电源控制** | PWR_CTRL (GPIO5) 控制屏幕电源开关 |

> **注意**：LCD 使用 GPIO5 作为电源控制引脚，因此 GPIO5 默认不可用于其他功能。

## 三、Shuttle Board 传感器子板

ESP-SensairShuttle 通过 Shuttle Board 接口连接传感器子板，支持以下两款官方子板：

### 3.1 ShuttleBoard-BMI270 & BMM350（IMU + 磁力计）

| 传感器 | 型号 | 接口 | 用途 |
|--------|------|------|------|
| **6 轴 IMU** | BMI270 | I2C/SPI | 加速度 + 陀螺仪，跌倒检测核心 |
| **3 轴磁力计** | BMM350 | I2C | 磁场方向检测 |

#### BMI270 详细参数

| 参数 | 值 |
|------|-----|
| **制造商** | Bosch Sensortec |
| **接口** | I2C (支持 SPI) |
| **I2C 地址** | 0x68 (SDO 接地) / 0x69 (SDO 接 VDDIO) |
| **加速度计量程** | ±2g / ±4g / ±8g / ±16g（可配置） |
| **陀螺仪量程** | ±125°/s / ±250°/s / ±500°/s / ±1000°/s / ±2000°/s（可配置） |
| **加速度计 ODR** | 最高 1600Hz |
| **陀螺仪 ODR** | 最高 3200Hz |
| **FIFO** | 2048 字节 |
| **工作电压** | 1.2V - 3.6V |

#### BMI270 关键寄存器

| 寄存器 | 地址 | 用途 |
|--------|------|------|
| `BMI270_REG_CHIP_ID` | 0x00 | 芯片 ID (应为 0x24) |
| `BMI270_REG_ACC_CONF` | 0x40 | 加速度计配置 |
| `BMI270_REG_GYR_CONF` | 0x42 | 陀螺仪配置 |
| `BMI270_REG_ACC_DATA` | 0x12 | 加速度数据 (6 字节: X, Y, Z) |
| `BMI270_REG_GYR_DATA` | 0x18 | 陀螺仪数据 (6 字节: X, Y, Z) |
| `BMI270_REG_FIFO_DATA` | 0x26 | FIFO 数据 |
| `BMI270_REG_FIFO_LENGTH` | 0x24 | FIFO 长度 |
| `BMI270_REG_CMD` | 0x7E | 命令寄存器 |

#### BMI270 初始化序列

1. 读取 `CHIP_ID` (0x00) 确认设备存在（期望值 0x24）
2. 配置加速度计：`ACC_CONF` 设置量程 ±8g，ODR 100Hz
3. 配置陀螺仪：`GYR_CONF` 设置量程 ±1000°/s，ODR 100Hz
4. 写入 `CMD` 寄存器 0xB0 使能传感器

### 3.2 ShuttleBoard-BME690（环境传感器）

| 参数 | 值 |
|------|-----|
| **型号** | BME690 |
| **制造商** | Bosch Sensortec |
| **接口** | I2C (支持 SPI) |
| **I2C 地址** | 0x76 (SDO 接地) / 0x77 (SDO 接 VDDIO) |
| **测量参数** | 温度、湿度、气压、空气质量 (IAQ) |
| **温度精度** | ±0.5°C |
| **湿度精度** | ±3% RH |
| **气压精度** | ±0.12 hPa |
| **工作电压** | 1.2V - 3.6V |

> **注意**：BME690 的 IAQ（室内空气质量）算法需要 BSEC 库支持，在 ESP32 上移植较复杂。如非必需，可仅读取温湿气压数据。
